# Changelog

All notable changes to LabKit are documented in this file.

## [1.5.0] - 2026-11-10

### Added
- Modrinth README Generator.
- Markdown preview for generated README content.
- Copy and download actions for README output.
- Fields for project information, features, installation, dependencies, compatibility, credits, links, and additional notes.

## [1.4.0] - 2026-11-10

### Added
- Dependency Checker for `fabric.mod.json`.
- Basic checks for required metadata, dependencies, entrypoints, and mixin declarations.
- Copy and download options for the generated report.
- Example metadata for testing.

## [1.3.0] - 2026-11-10

### Added
- Client Entrypoint Generator.
- Optional client initializer generation in Fabric projects.
- Mixin configuration template generation.
- Optional example Mixin class.

## [1.2.0] - 2026-11-10

### Added
- Fabric Project Generator.
- ZIP export for generated starter projects.
- Project metadata and Gradle configuration templates.

## [1.1.0] - 2026-11-10

### Added
- Pink Laboratory visual redesign.
- Recent activity history.
- About section and responsive layout refinements.

## [1.0.0] - 2026-11-10

### Added
- Initial LabKit release.
- JSON Formatter.
- UUID Generator.
- Fabric Metadata Generator.
- Color Converter.
- Changelog Builder.
