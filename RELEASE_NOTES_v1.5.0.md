# LabKit v1.5.0 — Initial Public Release

LabKit is a lightweight browser-based toolkit for Minecraft mod developers.

## Included tools

- JSON Formatter
- UUID Generator
- Fabric Metadata
- Fabric Project Generator
- Client Entrypoint Generator
- Mixin Template Generator
- Color Converter
- Changelog Builder
- Dependency Checker
- Modrinth README Generator

## How to use

Download `LabKit-v1.5.0.html` and open it in a modern browser. No installation or backend is required.

## Important notes

- ZIP generation loads JSZip from a CDN and requires an internet connection.
- Generated Fabric projects are starter templates and are not compiled automatically.
- Dependency Checker performs basic metadata checks; always verify your project with Gradle and the relevant mod-loader documentation.

This is the first public release of LabKit.
