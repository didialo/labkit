Developer tool / 04

Fabric Project Generator

Create a starter Fabric mod project and download its files in one ZIP.

🧩 Project identity
⚙ Minecraft and Fabric configuration
The initial values are based on a previously used setup. Check that the selected Minecraft, Loader, API, Loom, Gradle and Java versions are compatible before building. The generator does not query live version compatibility.
☕ Java package and entrypoint
Example: package com.example.mymod and class MyMod create src/main/java/com/example/mymod/MyMod.java.
✦ Optional project components

Adds a separate ClientModInitializer class and registers it in fabric.mod.json.

Adds a Mixin configuration and an empty example mixin class. It does not modify Minecraft behavior until you add valid injections or overwrite logic.

Use the correct mapped target class for your Minecraft version and mappings.

About LabKit

A little toolbox for curious developers.

🧪

LabKit v1.5.0

LabKit is a collection of simple browser-based utilities designed to make everyday development tasks a little easier.

✦ Created by

Miss Heaven's Mod Lab

An independent project laboratory for unusual mods, useful tools and strange experiments.

♡ What's included
  • JSON formatting and validation.
  • UUID v4 generation.
  • Fabric metadata template generation.
  • Fabric project ZIP generation with client entrypoint and Mixin starter options.
  • Fabric dependency and metadata inspection.
  • Modrinth README generation with Markdown preview.
  • HEX, RGB and HSL color conversion.
  • Markdown changelog creation.
  • Local recent activity history.
